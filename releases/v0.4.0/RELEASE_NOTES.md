# MealLog 0.4.0 · 自动预测与累计模型检验

- 次日体重预测自动从前一天实测体重和热量缺口生成，不再需要每天确认。
- 误差统一为 **预测 − 实际（kg）**，保留正负号；直方图、曲线、长图和 CSV 口径一致。
- 趋势页增加“累计预测”，默认最近 30 天并支持自定义区间。只用最早有效称重作为 W₀，后续基础代谢和 MET 用递推体重，实测仅作对照。
- 漏称不影响累计推算；必要的饮食/运动收支数据缺失时断开曲线，补齐后续算。
- 饮食和运动编辑器增加可搜索的离线热量/MET 参考表，可主动采用后再编辑。
- ZIP 导出升级为 2.0，同时包含逐日与累计数据及复算上下文；原始记录和历史快照保留。

已通过 35 项单元测试和 16 项 Android 14 真机测试。完成覆盖升级及原有记录、照片、设置的一致性验证。

下载 `MealLog-0.4.0.apk` 后覆盖安装即可；版本号 0.4.0，versionCode 5，Android 8.0 及以上。沿用原自用版本的调试签名，无需卸载旧应用。

APK 不包含个人记录、饮食照片、模型设置或签名私钥。`SHA256SUMS` 可用于核对安装包。
